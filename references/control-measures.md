# 控制措施库

## 控制层级原则

```
消除 → 替代 → 工程控制 → 行政管理 → PPE
（优先级由高到低）
```

---

## 1. 工程控制

### 1.1 隔离（上锁挂牌 LOTO）

**依据：** CEM 手册 C.1.13、法规 §165

**程序：**
1. 识别所有能源（电力/水/气/蒸汽/化学品）
2. 通知所有受影响人员
3. 隔离能源 → 上锁 → 挂牌（标明：谁锁的、为什么、什么时候）
4. 尝试启动确认零能量状态
5. 完成工作后按反向顺序拆锁还原

**挂牌格式：**
```
⚠️ 危险 — 禁止操作
设备：[设备名称]
锁定人：[姓名]
日期：[日期]
原因：[密闭空间作业]
```

### 1.2 清洗/净化

**依据：** 密闭空间风险指南「安全措施」

| 清洗方式 | 适用场景 | 注意事项 |
|:---------|:---------|:---------|
| 水清洗 | 化学品残留 | 控制排水，防止二次污染 |
| 蒸汽清洗 | 重油/黏性物质 | 注意高温灼伤风险 |
| 通风吹扫 | 可燃气体/挥发性物质 | 必须用防爆风机 |
| 化学中和 | 酸碱残留 | 确认中和反应完成 |

### 1.3 通风

**依据：** 密闭空间风险指南「通风」

**要求：**
- 机械通风 ≥ 30 分钟（进入前）
- 通风期间连续监测气体
- 出风口位置：新鲜空气进入 → 污染空气排出
- 风量计算：至少每小时换气 20 次

**风量计算公式：**
```
所需风量 (m³/h) = 空间体积 (m³) × 20 (次/小时)
```

**通风设备选择：**
| 空间尺寸 | 推荐设备 |
|:---------|:---------|
| <10m³ | 便携式轴流风机 |
| 10-50m³ | 中型防爆风机 |
| >50m³ | 工业风机 + 导风管 |

### 1.4 验气

**依据：** 密闭空间风险指南「验气」

**标准：**
| 参数 | 安全范围 | 报警阈值 |
|:-----|:---------|:---------|
| O₂ | 19.5% - 23.5% | <20% 或 >23% |
| CO | ≤ 25 ppm | >15 ppm |
| H₂S | ≤ 10 ppm | >5 ppm |
| LEL | ≤ 10% | >5% |

**程序：**
1. 通风后等待 ≥30 分钟
2. 从出入口 3 个深度分层测量（上/中/下）
3. 连续监测 — 不仅是进入前一次性
4. 记录每次读数

## 2. 行政管理

### 2.1 工作许可证

**依据：** 法规 §163

**许可证有效期：** 最长一个班次，不得跨班

**许可条件清单（标准 12 项）：**
1. [ ] 危险评估已完成
2. [ ] LOTO 已执行
3. [ ] 通风 ≥30 分钟且气体合格
4. [ ] 所有进入人员已接受 TBT
5. [ ] 当值员已到位
6. [ ] 通讯设备已就位且测试
7. [ ] PPE 已配备并检查
8. [ ] 救援设备已就位
9. [ ] 照明设备（防爆）已就位
10. [ ] 进出登记表已准备
11. [ ] 应急预案已告知所有人员
12. [ ] 工作范围确认无扩大

### 2.2 人员配置

| 角色 | 要求 | 数量 |
|:-----|:-----|:-----|
| 合资格人员 | 持安全资格证书，负责评估审批 | 1 名 |
| 指定人员（进入者） | 已接受培训，持有许可证 | 按需 |
| 当值员（监护人） | 不得兼职，必须全程在场 | 1 名 |
| 救援人员 | 已受训，配备救援装备待命 | 1-2 名 |

### 2.3 培训（TBT）

**培训内容：**
- 密闭空间危害认识
- 气体检测仪使用
- PPE 正确穿戴
- 通风设备操作
- 紧急逃生程序
- 当值员职责

## 3. 个人防护装备（PPE）

| 危害场景 | 必备 PPE | 选配 PPE |
|:---------|:---------|:---------|
| 缺氧/有毒气体（高浓度） | SCBA 供气式呼吸器 | — |
| 有毒气体（低浓度，O₂正常） | 过滤式呼吸器（确认型号适用） | — |
| 坠落风险 | 全身安全带 + 救生绳 + 三脚架 | 安全帽 |
| 溺水风险 | 救生衣 | — |
| 爆炸环境 | 防爆工具 | 防爆对讲机 |
| 化学品接触 | 化学防护手套 + 护目镜 | 防护服 |
| 一般作业 | 安全帽 + 安全鞋 + 反光衣 | 耳塞/耳罩 |

## 4. 紧急救援

### 救援装备清单

| 装备 | 数量 | 用途 |
|:-----|:-----|:-----|
| 三脚架 | 1 套 | 人员提升/下降 |
| 绞盘/绞车 | 1 套 | 配合三脚架 |
| 救援绳 | 2 条 | 连接安全带 |
| 全身式安全带 | 按人数 | 每人一条 |
| SCBA | 2 套 | 救援人员使用 |
| 急救箱 | 1 套 | 基本急救 |
| 复苏器（CPR mask） | 1 个 | 人工呼吸 |
| 防爆对讲机 | 2 部 | 内外通讯 |
| 防爆照明 | 2 盏 | 应急照明 |

### 救援程序

```
1. 当值员发现异常 → 不进入空间
2. 立即通报现场主管 + 拨打紧急电话
3. 使用三脚架 + 绞盘尝试外部拉出
4. 外部救援失败 → 救援人员配戴 SCBA 进入
5. 救出后立即急救/ CPR
6. 通知 999（当地消防/救护）
```
