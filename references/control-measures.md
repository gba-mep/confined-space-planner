# 控制措施庫

## 控制層級原則

```
消除 → 替代 → 工程控制 → 行政管理 → PPE
（優先級由高到低）
```

---

## 1. 工程控制

### 1.1 隔離（上鎖掛牌 LOTO）

**依據：** CEM 手冊 C.1.13、法規 §165

**程序：**
1. 識別所有能源（電力/水/氣/蒸汽/化學品）
2. 通知所有受影響人員
3. 隔離能源 → 上鎖 → 掛牌（標明：誰鎖的、為什麼、什麼時候）
4. 嘗試啟動確認零能量狀態
5. 完成工作後按反向順序拆鎖還原

**挂牌格式：**
```
⚠️ 危險 — 禁止操作
設備：[設備名稱]
鎖定人：[姓名]
日期：[日期]
原因：[密閉空間作業]
```

### 1.2 清洗/淨化

**依據：** 密閉空間風險指南「安全措施」

| 清洗方式 | 適用場景 | 注意事項 |
|:---------|:---------|:---------|
| 水清洗 | 化學品殘留 | 控制排水，防止二次污染 |
| 蒸汽清洗 | 重油/黏性物質 | 注意高溫灼傷風險 |
| 通風吹掃 | 可燃氣體/揮發性物質 | 必須用防爆風機 |
| 化學中和 | 酸鹼殘留 | 確認中和反應完成 |

### 1.3 通風

**依據：** 密閉空間風險指南「通風」

**要求：**
- 機械通風 ≥ 30 分鐘（進入前）
- 通風期間連續監測氣體
- 出風口位置：新鮮空氣進入 → 污染空氣排出
- 風量計算：至少每小時換氣 20 次

**風量計算公式：**
```
所需風量 (m³/h) = 空間體積 (m³) × 20 (次/小時)
```

**通風設備選擇：**
| 空間尺寸 | 推薦設備 |
|:---------|:---------|
| <10m³ | 便携式軸流風機 |
| 10-50m³ | 中型防爆風機 |
| >50m³ | 工業風機 + 導風管 |

### 1.4 驗氣

**依據：** 密閉空間風險指南「驗氣」

**標準：**
| 參數 | 安全範圍 | 報警閾值 |
|:-----|:---------|:---------|
| O₂ | 19.5% - 23.5% | <20% 或 >23% |
| CO | ≤ 25 ppm | >15 ppm |
| H₂S | ≤ 10 ppm | >5 ppm |
| LEL | ≤ 10% | >5% |

**程序：**
1. 通風後等待 ≥30 分鐘
2. 從出入口 3 個深度分層測量（上/中/下）
3. 連續監測 — 不僅是進入前一次性
4. 記錄每次讀數

## 2. 行政管理

### 2.1 工作許可證

**依據：** 法規 §163

**許可證有效期：** 最長一個班次，不得跨班

**許可條件清單（標準 12 項）：**
1. [ ] 危險評估已完成
2. [ ] LOTO 已執行
3. [ ] 通風 ≥30 分鐘且氣體合格
4. [ ] 所有進入人員已接受 TBT
5. [ ] 當值員已到位
6. [ ] 通訊設備已就位且測試
7. [ ] PPE 已配備並檢查
8. [ ] 救援設備已就位
9. [ ] 照明設備（防爆）已就位
10. [ ] 進出登記表已準備
11. [ ] 應急預案已告知所有人員
12. [ ] 工作範圍確認無擴大

### 2.2 人員配置

| 角色 | 要求 | 數量 |
|:-----|:-----|:-----|
| 合資格人員 | 持安全資格證書，負責評估審批 | 1 名 |
| 指定人員（進入者） | 已接受培訓，持有許可證 | 按需 |
| 當值員（監護人） | 不得兼職，必須全程在場 | 1 名 |
| 救援人員 | 已受訓，配備救援裝備待命 | 1-2 名 |

### 2.3 培訓（TBT）

**培訓內容：**
- 密閉空間危害認識
- 氣體檢測儀使用
- PPE 正確穿戴
- 通風設備操作
- 緊急逃生程序
- 當值員職責

## 3. 個人防護裝備（PPE）

| 危害場景 | 必備 PPE | 選配 PPE |
|:---------|:---------|:---------|
| 缺氧/有毒氣體（高濃度） | SCBA 供氣式呼吸器 | — |
| 有毒氣體（低濃度，O₂正常） | 過濾式呼吸器（確認型號適用） | — |
| 墜落風險 | 全身安全帶 + 救生繩 + 三腳架 | 安全帽 |
| 溺水風險 | 救生衣 | — |
| 爆炸環境 | 防爆工具 | 防爆對講機 |
| 化學品接觸 | 化學防護手套 + 護目鏡 | 防護服 |
| 一般作業 | 安全帽 + 安全鞋 + 反光衣 | 耳塞/耳罩 |

## 4. 緊急救援

### 救援裝備清單

| 裝備 | 數量 | 用途 |
|:-----|:-----|:-----|
| 三腳架 | 1 套 | 人員提升/下降 |
| 絞盤/絞車 | 1 套 | 配合三腳架 |
| 救援繩 | 2 條 | 連接安全帶 |
| 全身式安全帶 | 按人數 | 每人一條 |
| SCBA | 2 套 | 救援人員使用 |
| 急救箱 | 1 套 | 基本急救 |
| 復蘇器（CPR mask） | 1 個 | 人工呼吸 |
| 防爆對講機 | 2 部 | 內外通訊 |
| 防爆照明 | 2 盞 | 應急照明 |

### 救援程序

```
1. 當值員發現異常 → 不進入空間
2. 立即通報現場主管 + 撥打緊急電話
3. 使用三腳架 + 絞盤嘗試外部拉出
4. 外部救援失敗 → 救援人員配戴 SCBA 進入
5. 救出後立即急救/ CPR
6. 通知 999（澳門消防/救護）
```
