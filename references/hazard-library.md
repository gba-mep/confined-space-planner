# 危害識別庫

## 氣體容忍標準

| 氣體 | 安全範圍 | 危險閾值 | 危害類型 |
|:-----|:---------|:---------|:---------|
| 氧氣 (O₂) | 19.5% - 23.5% | <19.5% 缺氧 / >23.5% 富氧 | 缺氧窒息 / 助燃爆炸 |
| 一氧化碳 (CO) | ≤ 25 ppm | >25 ppm | 中毒 |
| 硫化氫 (H₂S) | ≤ 10 ppm | >10 ppm | 劇毒（嗅覺麻痺） |
| 可燃氣體 (LEL) | ≤ 10% | >10% | 爆炸 |
| 揮發性有機物 (VOC) | 按具體物質 | 因物質而異 | 中毒 |

## 危害識別清單（4 維度）

### a. 大氣危害

| 危害 | 識別條件 | 來源 | 常見場景 |
|:-----|:---------|:-----|:---------|
| 缺氧 | O₂ < 19.5% | 生物呼吸/氧化反應 | 長期密封、腐爛有機物消耗氧 |
| 富氧 | O₂ > 23.5% | 氧氣洩漏/焊接供氧 | 焊接作業後氧氣殘留 |
| 可燃氣體 | > 10% LEL | 有機物分解/燃油洩漏 | 污水管、化學品儲罐 |
| CO 中毒 | > 25 ppm | 不完全燃燒/內燃機廢氣 | 發電機附近、焊接煙氣 |
| H₂S 中毒 | > 10 ppm | 硫酸鹽還原/污水分解 | 下水道、污水處理池 |
| VOC 中毒 | 超過物質限值 | 清潔劑/溶劑/塗料 | 使用天拿水、稀釋劑 |

### b. 物理危害

| 危害 | 識別條件 | 常見場景 |
|:-----|:---------|:---------|
| 觸電 | 潮濕環境 + 電動工具 | 儲水缸/管道內使用電動設備 |
| 機械夾傷 | 狹窄空間 + 旋轉設備 | 攪拌器、風機 |
| 墜落 | 深度 >2m + 無防護 | 沙井、管道井 |
| 高溫/熱應力 | 密封 + 無通風 + 夏季 | 屋頂水箱、鍋爐 |
| 低溫 | 冷凍管道/冷卻系統 | 冷氣管道維修 |
| 噪音 | 回聲 + 風機/水泵 | 狹小空間內使用風炮 |
| 淹溺 | 積水/液體涌入 | 水箱清洗、排水管道 |

### c. 物質危害

| 危害 | 識別條件 | 常見場景 |
|:-----|:---------|:---------|
| 液體涌入 | 管道未隔離 | 未上鎖掛牌的水管/閥門 |
| 化學灼傷 | 強酸/強鹼殘留 | 化學品儲罐清洗 |
| 粉塵爆炸 | 可燃粉塵濃度超限 | 穀倉、粉體輸送管道 |
| 輻射 | 工業放射源 | 特殊工業設施 |

### d. 土建/結構危害

| 危害 | 識別條件 | 常見場景 |
|:-----|:---------|:---------|
| 坍塌 | 無支撐的土方/結構 | 地下管道、基坑 |
| 陷落 | 地面承重不足 | 沙井蓋、地下空間頂板 |
| 掩埋 | 物料坍落 | 筒倉、貯槽內部 |
| 內部結構困住 | 狹窄/複雜內部 | 有隔層的管道、分歧管 |

## 按空間類型的常見危害速查

| 空間類型 | 主要危害 | 次要危害 |
|:---------|:---------|:---------|
| 沙井/下水道 | H₂S、缺氧、淹溺 | CO、墜落、掩埋 |
| 儲水缸/水箱 | 缺氧、觸電、墜落 | 細菌、淹溺 |
| 管道 | 缺氧、可燃氣體、物理困住 | 噪音、高溫 |
| 貯槽/儲罐 | VOC、缺氧、化學灼傷 | 粉塵爆炸、淹溺 |
| 鍋爐 | 高溫、缺氧 | 觸電、物理夾傷 |
| 隧道/地道 | 缺氧、坍塌、淹溺 | 噪音、粉塵、通風不足 |
| 地下室/地庫 | 缺氧、坍塌 | 淹溺、觸電 |
