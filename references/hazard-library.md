# 危害识别库

## 气体容忍标准

| 气体 | 安全范围 | 危险阈值 | 危害类型 |
|:-----|:---------|:---------|:---------|
| 氧气 (O₂) | 19.5% - 23.5% | <19.5% 缺氧 / >23.5% 富氧 | 缺氧窒息 / 助燃爆炸 |
| 一氧化碳 (CO) | ≤ 25 ppm | >25 ppm | 中毒 |
| 硫化氢 (H₂S) | ≤ 10 ppm | >10 ppm | 剧毒（嗅觉麻痹） |
| 可燃气体 (LEL) | ≤ 10% | >10% | 爆炸 |
| 挥发性有机物 (VOC) | 按具体物质 | 因物质而异 | 中毒 |

## 危害识别清单（4 维度）

### a. 大气危害

| 危害 | 识别条件 | 来源 | 常见场景 |
|:-----|:---------|:-----|:---------|
| 缺氧 | O₂ < 19.5% | 生物呼吸/氧化反应 | 长期密封、腐烂有机物消耗氧 |
| 富氧 | O₂ > 23.5% | 氧气泄漏/焊接供氧 | 焊接作业后氧气残留 |
| 可燃气体 | > 10% LEL | 有机物分解/燃油泄漏 | 污水管、化学品储罐 |
| CO 中毒 | > 25 ppm | 不完全燃烧/内燃机废气 | 发电机附近、焊接烟气 |
| H₂S 中毒 | > 10 ppm | 硫酸盐还原/污水分解 | 下水道、污水处理池 |
| VOC 中毒 | 超过物质限值 | 清洁剂/溶剂/涂料 | 使用天拿水、稀释剂 |

### b. 物理危害

| 危害 | 识别条件 | 常见场景 |
|:-----|:---------|:---------|
| 触电 | 潮湿环境 + 电动工具 | 储水缸/管道内使用电动设备 |
| 机械夹伤 | 狭窄空间 + 旋转设备 | 搅拌器、风机 |
| 坠落 | 深度 >2m + 无防护 | 沙井、管道井 |
| 高温/热应力 | 密封 + 无通风 + 夏季 | 屋顶水箱、锅炉 |
| 低温 | 冷冻管道/冷却系统 | 冷气管道维修 |
| 噪音 | 回声 + 风机/水泵 | 狭小空间内使用风炮 |
| 淹溺 | 积水/液体涌入 | 水箱清洗、排水管道 |

### c. 物质危害

| 危害 | 识别条件 | 常见场景 |
|:-----|:---------|:---------|
| 液体涌入 | 管道未隔离 | 未上锁挂牌的水管/阀门 |
| 化学灼伤 | 强酸/强碱残留 | 化学品储罐清洗 |
| 粉尘爆炸 | 可燃粉尘浓度超限 | 谷仓、粉体输送管道 |
| 辐射 | 工业放射源 | 特殊工业设施 |

### d. 土建/结构危害

| 危害 | 识别条件 | 常见场景 |
|:-----|:---------|:---------|
| 坍塌 | 无支撑的土方/结构 | 地下管道、基坑 |
| 陷落 | 地面承重不足 | 沙井盖、地下空间顶板 |
| 掩埋 | 物料坍落 | 筒仓、贮槽内部 |
| 内部结构困住 | 狭窄/复杂内部 | 有隔层的管道、分歧管 |

## 按空间类型的常见危害速查

| 空间类型 | 主要危害 | 次要危害 |
|:---------|:---------|:---------|
| 沙井/下水道 | H₂S、缺氧、淹溺 | CO、坠落、掩埋 |
| 储水缸/水箱 | 缺氧、触电、坠落 | 细菌、淹溺 |
| 管道 | 缺氧、可燃气体、物理困住 | 噪音、高温 |
| 贮槽/储罐 | VOC、缺氧、化学灼伤 | 粉尘爆炸、淹溺 |
| 锅炉 | 高温、缺氧 | 触电、物理夹伤 |
| 隧道/地道 | 缺氧、坍塌、淹溺 | 噪音、粉尘、通风不足 |
| 地下室/地库 | 缺氧、坍塌 | 淹溺、触电 |
