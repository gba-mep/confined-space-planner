# 法规摘要

## 一、[当地安全法规]

### §161 — 密闭空间定义与危险评估

法定密闭空间 = 任何被围封的空间，可能产生以下 6 种危险之一：
1. 爆炸
2. 缺氧
3. 中毒
4. 遇溺
5. 高温
6. 高压

**危险评估报告（6 项必填内容）：**
1. 工作地点描述
2. 可能存在的危害
3. 风险评估方法与结果
4. 控制措施
5. 应急预案
6. 评估人员签署

### §163 — 工作许可证制度

**许可证（4 项必填内容）：**
1. 工作内容与范围
2. 有效期限
3. 许可条件（安全措施）
4. 签发人与签收人

### §165 — 17 项安全措施

1. 确认空间为密闭空间
2. 危险评估已进行
3. 工作许可证已签发
4. 合资格人员已指定
5. 工作人员已接受培训
6. 进入前已通风（≥30 分钟）
7. 连续气体监测
8. 通风设备持续运行
9. 上锁挂牌（LOTO）已执行
10. 当值员已到位
11. 通讯设备已就位
12. 紧急救援设备已就位
13. 救援人员已待命
14. PPE 已配备并检查
15. 进出登记制度
16. 照明设备（防爆）
17. 工作完成后确认人员全部撤离

### §166-167 — 人员资格与培训
- 合资格人员（安全主任/工程师）负责评估与审批
- 所有进入人员必须接受密闭空间安全培训（TBT）

### §168-172 — 地下工程附加要求
- 土方支撑
- 地下水控制
- 相邻结构保护
- 通风增强要求

## 二、[安全管理手册]

### A.2.5 — 安全计划构成元素
安全计划必须包含：风险评估、安全措施、应急预案、人员培训、监督制度

### A.2.10 — 高风险工程定义
密闭空间作业自动列为高风险工程，需要：
- 加强监督频率
- 安全主管签批
- 额外培训记录

### A.3.2 — 合资格人员要求
- 必须持有认可的安全资格证书
- 负责签发工作许可证
- 有权停止不安全作业

### C.1.8 — 密闭空间工程检查清单
- 当值员是否到位
- 连续通风是否运行
- 气体监测是否连续
- O₂ / 气体水平是否在安全范围
- 通信是否正常
- 救援设备是否就位

### C.1.13 — 上锁挂牌（LOTO）程序
- 识别所有能源（电力/水/气/化学品）
- 隔离 + 上锁 + 挂牌
- 尝试启动确认零能量状态
- 还原程序（按反向顺序拆锁）

### C.1.25 — 土建/结构安全
- 检查支撑结构完整性
- 评估坍塌/陷落风险
- 必要时增加临时支撑

## 三、ISO 31000 风险管理框架

### 风险评估公式
```
风险分数 = 严重性 × 可能性
```

### 严重性等级

| 等级 | 分数 | 描述 |
|:-----|:-----|:-----|
| 灾难性 | 5 | 死亡或永久残废 |
| 严重 | 4 | 严重受伤需住院 |
| 中等 | 3 | 受伤需医疗处理 |
| 轻微 | 2 | 轻伤可自行处理 |
| 微小 | 1 | 无伤害仅财产损失 |

### 可能性等级

| 等级 | 分数 | 描述 |
|:-----|:-----|:-----|
| 几乎确定 | 5 | 每次都可能发生 |
| 很可能 | 4 | 经常发生 |
| 可能 | 3 | 偶尔发生 |
| 不太可能 | 2 | 很少发生 |
| 极不可能 | 1 | 理论上可发生 |

### 风险等级矩阵

| 等级 | 分数范围 | 处理要求 |
|:-----|:---------|:---------|
| 极高风险 | 20-15 | 禁止作业，必须消除风险后重新评估 |
| 高风险 | 12-8 | 需高级控制 + 项目经理审批 |
| 中风险 | 6-4 | 需控制措施 + 当值员监护 |
| 低风险 | 3-1 | 常规 PPE + 监护 |
