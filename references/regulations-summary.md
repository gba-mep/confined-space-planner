# 法規摘要

## 一、澳門第32/2023號行政法規

### §161 — 密閉空間定義與危險評估

法定密閉空間 = 任何被圍封的空間，可能產生以下 6 種危險之一：
1. 爆炸
2. 缺氧
3. 中毒
4. 遇溺
5. 高溫
6. 高壓

**危險評估報告（6 項必填內容）：**
1. 工作地點描述
2. 可能存在的危害
3. 風險評估方法與結果
4. 控制措施
5. 應急預案
6. 評估人員簽署

### §163 — 工作許可證制度

**許可證（4 項必填內容）：**
1. 工作內容與範圍
2. 有效期限
3. 許可條件（安全措施）
4. 簽發人與簽收人

### §165 — 17 項安全措施

1. 確認空間為密閉空間
2. 危險評估已進行
3. 工作許可證已簽發
4. 合資格人員已指定
5. 工作人員已接受培訓
6. 進入前已通風（≥30 分鐘）
7. 連續氣體監測
8. 通風設備持續運行
9. 上鎖掛牌（LOTO）已執行
10. 當值員已到位
11. 通訊設備已就位
12. 緊急救援設備已就位
13. 救援人員已待命
14. PPE 已配備並檢查
15. 進出登記制度
16. 照明設備（防爆）
17. 工作完成後確認人員全部撤離

### §166-167 — 人員資格與培訓
- 合資格人員（安全主任/工程師）負責評估與審批
- 所有進入人員必須接受密閉空間安全培訓（TBT）

### §168-172 — 地下工程附加要求
- 土方支撐
- 地下水控制
- 相鄰結構保護
- 通風增強要求

## 二、CEM 承建商安全管理手冊

### A.2.5 — 安全計劃構成元素
安全計劃必須包含：風險評估、安全措施、應急預案、人員培訓、監督制度

### A.2.10 — 高風險工程定義
密閉空間作業自動列為高風險工程，需要：
- 加強監督頻率
- 安全主管簽批
- 額外培訓記錄

### A.3.2 — 合資格人員要求
- 必須持有認可的安全資格證書
- 負責簽發工作許可證
- 有權停止不安全作業

### C.1.8 — 密閉空間工程檢查清單
- 當值員是否到位
- 連續通風是否運行
- 氣體監測是否連續
- O₂ / 氣體水平是否在安全範圍
- 通信是否正常
- 救援設備是否就位

### C.1.13 — 上鎖掛牌（LOTO）程序
- 識別所有能源（電力/水/氣/化學品）
- 隔離 + 上鎖 + 掛牌
- 嘗試啟動確認零能量狀態
- 還原程序（按反向順序拆鎖）

### C.1.25 — 土建/結構安全
- 檢查支撐結構完整性
- 評估坍塌/陷落風險
- 必要時增加臨時支撐

## 三、ISO 31000 風險管理框架

### 風險評估公式
```
風險分數 = 嚴重性 × 可能性
```

### 嚴重性等級

| 等級 | 分數 | 描述 |
|:-----|:-----|:-----|
| 災難性 | 5 | 死亡或永久殘廢 |
| 嚴重 | 4 | 嚴重受傷需住院 |
| 中等 | 3 | 受傷需醫療處理 |
| 輕微 | 2 | 輕傷可自行處理 |
| 微小 | 1 | 無傷害僅財產損失 |

### 可能性等級

| 等級 | 分數 | 描述 |
|:-----|:-----|:-----|
| 幾乎確定 | 5 | 每次都可能發生 |
| 很可能 | 4 | 經常發生 |
| 可能 | 3 | 偶爾發生 |
| 不太可能 | 2 | 很少發生 |
| 極不可能 | 1 | 理論上可發生 |

### 風險等級矩陣

| 等級 | 分數範圍 | 處理要求 |
|:-----|:---------|:---------|
| 極高風險 | 20-15 | 禁止作業，必須消除風險後重新評估 |
| 高風險 | 12-8 | 需高級控制 + 項目經理審批 |
| 中風險 | 6-4 | 需控制措施 + 當值員監護 |
| 低風險 | 3-1 | 常規 PPE + 監護 |
