# 用戶輸入規範

生成密閉空間施工計劃需要用戶提供以下 4 類參數：

## 1. 項目基本信息

| 參數 | 說明 | 示例 |
|:-----|:-----|:-----|
| 項目名稱 | 工程全稱 | XX酒店外牆維修工程 |
| 項目地點 | 工地地址 | 澳門XX街XX號 |
| 總包商/承建商 | 公司全稱 | XXX建築有限公司 |

## 2. 目標密閉空間描述

| 參數 | 說明 | 示例 |
|:-----|:-----|:-----|
| 空間類型 | 沙井/儲水缸/管道/貯槽/鍋爐/隧道等 | 儲水缸 |
| 空間尺寸 | 長x寬x高 或 直徑x深度 | 3m x 3m x 3m |
| 空間位置 | 具體位置描述 | 16樓天台 |
| 出入口數量與尺寸 | 數量 + 寬高 | 1個，70x70cm 方形井口 |
| 內部結構 | 隔層/梯子/內部設備 | 有爬梯，無隔層 |
| 周邊環境 | 交通/公眾區域 | 靠近電梯机房，非公眾區域 |

## 3. 預定工作內容

| 參數 | 說明 | 示例 |
|:-----|:-----|:-----|
| 工作性質 | 清洗/維修/焊接/灌漿/檢測 | 清洗 |
| 預計工作人員數 | 工人 + 監護 | 2名工作，1名外部監護 |
| 預計工時/班次 | 每班時長 + 班次數 | 每班4小時，共1個班次 |
| 使用的物料/設備 | 化學品/工具/設備 | 清潔劑、高壓水槍 |

## 4. 特殊要求

| 參數 | 說明 | 示例 |
|:-----|:-----|:-----|
| 業主/總包特殊要求 | 業主附加條件 | 需提交風險評估副本、CEM安全手冊適用 |
| 已知特殊危害 | 已識別的額外風險 | 可能存在硫化氫、積水 |

## 密閉空間法定定義（32/2023法規 §161）

以下 6 種危險之一即構成法定密閉空間：

1. **爆炸** — 可燃氣體/粉塵濃度超過安全限值
2. **缺氧** — 氧氣濃度 < 19.5%
3. **中毒** — 有毒氣體超過暴露限值
4. **遇溺** — 液體涌入/積水
5. **高溫** — 環境溫度極端
6. **高壓** — 管道/容器內殘餘壓力
