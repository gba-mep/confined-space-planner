# 用户输入规范

生成密闭空间施工计划需要用户提供以下 4 类参数：

## 1. 项目基本信息

| 参数 | 说明 | 示例 |
|:-----|:-----|:-----|
| 项目名称 | 工程全称 | XX酒店外墙维修工程 |
| 项目地点 | 工地地址 | XX街XX号 |
| 总包商/承建商 | 公司全称 | XXX建筑有限公司 |

## 2. 目标密闭空间描述

| 参数 | 说明 | 示例 |
|:-----|:-----|:-----|
| 空间类型 | 沙井/储水缸/管道/贮槽/锅炉/隧道等 | 储水缸 |
| 空间尺寸 | 长x宽x高 或 直径x深度 | 3m x 3m x 3m |
| 空间位置 | 具体位置描述 | 16楼天台 |
| 出入口数量与尺寸 | 数量 + 宽高 | 1个，70x70cm 方形井口 |
| 内部结构 | 隔层/梯子/内部设备 | 有爬梯，无隔层 |
| 周边环境 | 交通/公众区域 | 靠近电梯机房，非公众区域 |

## 3. 预定工作内容

| 参数 | 说明 | 示例 |
|:-----|:-----|:-----|
| 工作性质 | 清洗/维修/焊接/灌浆/检测 | 清洗 |
| 预计工作人员数 | 工人 + 监护 | 2名工作，1名外部监护 |
| 预计工时/班次 | 每班时长 + 班次数 | 每班4小时，共1个班次 |
| 使用的物料/设备 | 化学品/工具/设备 | 清洁剂、高压水枪 |

## 4. 特殊要求

| 参数 | 说明 | 示例 |
|:-----|:-----|:-----|
| 业主/总包特殊要求 | 业主附加条件 | 需提交风险评估副本、CEM安全手册适用 |
| 已知特殊危害 | 已识别的额外风险 | 可能存在硫化氢、积水 |

## 密闭空间法定定义（[法规编号]法规 §161）

以下 6 种危险之一即构成法定密闭空间：

1. **爆炸** — 可燃气体/粉尘浓度超过安全限值
2. **缺氧** — 氧气浓度 < 19.5%
3. **中毒** — 有毒气体超过暴露限值
4. **遇溺** — 液体涌入/积水
5. **高温** — 环境温度极端
6. **高压** — 管道/容器内残余压力
