# confined-space-planner

密閉空間施工計劃生成器（澳門法規）

基於澳門第32/2023號行政法規、CEM 承建商安全管理手冊及 ISO 31000，自動生成合法、合規的《密閉空間施工計劃》。

## 觸發詞

密閉空間、密閉空間施工計劃、confined space、危險評估報告、工作許可證、密閉空間安全、沙井作業、儲水缸作業、管道作業

## 安裝

```bash
pip install -e .
```

## 依賴

- Python >= 3.10
- pywin32
- python-docx
- openpyxl
- pandas

## 法規依據

| 法規 | 用途 |
|:-----|:-----|
| 澳門第32/2023號行政法規 §161-172 | 法定定義、危險評估、許可證、17項安全措施 |
| CEM 承建商安全管理手冊 A.2.5/C.1.8 | 項目級標準、合資格人員、檢查清單 |
| ISO 31000 + 密閉空間風險指南 | 風險矩陣、危害識別、控制措施層級 |

## 輸出文檔結構

封面 → 編制依據 → 工程概況 → 危險評估報告 → 工作許可證 → 安全措施 → 應急預案 → 附件
